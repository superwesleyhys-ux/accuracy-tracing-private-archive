# 分阶段 ψ：实现与开发测试

## 本次结论

分阶段提示词、定向修复内回环和两轮外层验证已实现。186 项离线测试通过。真实模型解读是否通过仍待验证：两个预先指定的案例均在首次 API 请求收到 RateLimitError，没有模型回答，不能算作语义判断错误，也不能宣称修复已提升准确率。

## 职责拆分

1. atoms：拆解主体、谓词、数值与单位、时间、比较基准、适用范围、否定与条件；限定语绑定其原句。
2. lineage：只识别有原文依据的来源关系及原始材料角色。
3. critic：检查上述两个输出；指出原文和具体缺陷，只退回对应阶段，最多一次定向修复，再复核。仍未通过则显式失败。
4. Python：生成稳定编号、定位原文、组装引用关系，执行状态一致性校验。
5. evidence：检查指定材料实际表达什么。
6. world：分别检查现有证据是否足以支持现实事实。外层缺口回传下一轮 ψ，目标保持不变。

提示词和完整流程见 `../docs/STAGED_PSI.md`。

## 状态缺陷修复

不同材料对同一编号的冲突定义现在被拒绝；同一材料仍可完整修订。缺口必须先登记才能关闭，验证器不能关闭溯源阶段的缺口。无效修订不会污染先前接受的状态。完整替换会重新核验并保留仍有依据的发现，允许有理由的撤回。checkpoint 升级为 v2，旧版本需重跑生成，不能伪造缺失历史。
